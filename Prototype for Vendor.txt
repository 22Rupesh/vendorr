==============================================================================
                         PROJECT OVERVIEW
==============================================================================

This project is a full-stack Vendor & Product Management System developed
for Relaxo Footwears Limited. It is a cloud-deployed, enterprise-grade
platform for managing products, vendors, vendor transactions, and sales
reporting with a premium dark-themed UI.


TECHNOLOGY STACK
----------------

  Layer         Technology
  ----------    --------------------------------------------------------
  Frontend      React.js 19, React Router 7, Tailwind CSS 3
  Backend       Node.js, Express 5, REST API
  Database      Supabase (Cloud PostgreSQL)
  Auth          bcryptjs (Password Hashing)
  Hosting       Vercel (Frontend), Render (Backend), Supabase (Database)


FEATURES
--------

  1. User Authentication
     - User Signup (Create Account)
     - User Login
     - Reset Password

  2. Dashboard
     - Central navigation hub with card-based menu
     - Quick access to all modules

  3. Product Master
     - Add new products (Name, Quantity, Price)
     - Edit existing products
     - Delete products
     - Increase / Decrease quantity with +/- buttons
     - Real-time quantity tracking

  4. Product List
     - View all products in a table
     - Displays Product ID, Name, Quantity, Price

  5. Vendor Master
     - Add vendor details (Name, Email, PAN, Mobile)
     - Edit vendor information
     - Delete vendors
     - Full CRUD operations

  6. Vendor List
     - View all vendors in a table
     - Displays Vendor ID, Name, Email, PAN, Mobile
     - "View Details" button for each vendor

  7. Vendor Details
     - Full vendor profile display
     - Transaction history for each vendor
     - Add new product transactions to a vendor
     - Auto-calculated: Total Amount, Paid Amount, Balance
     - Color-coded balance (Green = surplus, Red = dues)

  8. Sales Report
     - Complete transaction report across all vendors
     - Summary cards: Total Amount, Total Paid, Total Balance
     - Vendor name and Product name displayed per transaction
     - Full table with 8 columns: ID, Vendor, Product, Qty,
       Price, Total, Paid, Balance
     - Indian Rupee (₹) formatting with locale separators

==============================================================================
                  SQL QUERIES (All API Operations)
==============================================================================

  The backend uses Supabase REST API which internally translates to
  PostgreSQL queries. Below are the equivalent SQL queries for every
  operation used in the application.


  ---------------------------------------------------------------
  1. CREATE TABLE QUERIES (Database Setup)
  ---------------------------------------------------------------

  -- USERS TABLE
  CREATE TABLE "Users" (
      "UserId"       SERIAL PRIMARY KEY,
      "Username"     VARCHAR(255) UNIQUE NOT NULL,
      "PasswordHash" TEXT NOT NULL,
      "Mobile"       VARCHAR(20),
      "Email"        VARCHAR(255)
  );

  -- PRODUCTS TABLE
  CREATE TABLE "Products" (
      "ProductId"   SERIAL PRIMARY KEY,
      "ProductName" VARCHAR(255) NOT NULL,
      "Quantity"    INTEGER DEFAULT 0,
      "Price"       NUMERIC(10,2) DEFAULT 0
  );

  -- VENDORS TABLE
  CREATE TABLE "Vendors" (
      "VendorId" SERIAL PRIMARY KEY,
      "Name"     VARCHAR(255) NOT NULL,
      "Email"    VARCHAR(255),
      "PAN"      VARCHAR(50),
      "Mobile"   VARCHAR(20)
  );

  -- VENDOR TRANSACTIONS TABLE
  CREATE TABLE "VendorTransactions" (
      "TransactionId" SERIAL PRIMARY KEY,
      "VendorId"      INTEGER REFERENCES "Vendors"("VendorId"),
      "ProductId"     INTEGER REFERENCES "Products"("ProductId"),
      "Quantity"      INTEGER NOT NULL,
      "Price"         NUMERIC(10,2) NOT NULL,
      "TotalAmount"   NUMERIC(10,2) NOT NULL,
      "PaidAmount"    NUMERIC(10,2) DEFAULT 0,
      "Balance"       NUMERIC(10,2) DEFAULT 0
  );


  ---------------------------------------------------------------
  2. AUTHENTICATION QUERIES
  ---------------------------------------------------------------

  -- CHECK IF USER EXISTS (Used in: POST /signup)
  SELECT "UserId"
  FROM "Users"
  WHERE "Username" = 'testuser';

  -- CREATE NEW USER (Used in: POST /signup)
  INSERT INTO "Users" ("Username", "PasswordHash", "Mobile", "Email")
  VALUES ('testuser', '$2b$10$hashedpassword...', '1234567890', 'test@test.com');

  -- GET USER FOR LOGIN (Used in: POST /login)
  SELECT *
  FROM "Users"
  WHERE "Username" = 'testuser';

  -- CHECK USER EXISTS FOR PASSWORD RESET (Used in: POST /reset-password)
  SELECT "UserId"
  FROM "Users"
  WHERE "Username" = 'testuser';

  -- UPDATE PASSWORD (Used in: POST /reset-password)
  UPDATE "Users"
  SET "PasswordHash" = '$2b$10$newhashedpassword...'
  WHERE "Username" = 'testuser';


  ---------------------------------------------------------------
  3. PRODUCT QUERIES
  ---------------------------------------------------------------

  -- ADD NEW PRODUCT (Used in: POST /product/add)
  INSERT INTO "Products" ("ProductName", "Quantity", "Price")
  VALUES ('Slipper', 7, 999.00);

  -- LIST ALL PRODUCTS (Used in: GET /product/list)
  SELECT *
  FROM "Products"
  ORDER BY "ProductId" DESC;

  -- UPDATE PRODUCT (Used in: PUT /product/update)
  UPDATE "Products"
  SET "ProductName" = 'Updated Slipper',
      "Quantity"    = 10,
      "Price"       = 1099.00
  WHERE "ProductId" = 1;

  -- DELETE PRODUCT (Used in: DELETE /product/delete/:id)
  DELETE FROM "Products"
  WHERE "ProductId" = 1;

  -- GET PRODUCT QUANTITY (Used in: PUT /product/increase)
  SELECT "Quantity"
  FROM "Products"
  WHERE "ProductId" = 1;

  -- INCREASE PRODUCT QUANTITY (Used in: PUT /product/increase)
  UPDATE "Products"
  SET "Quantity" = "Quantity" + 1
  WHERE "ProductId" = 1;

  -- DECREASE PRODUCT QUANTITY (Used in: PUT /product/decrease)
  UPDATE "Products"
  SET "Quantity" = GREATEST("Quantity" - 1, 0)
  WHERE "ProductId" = 1;


  ---------------------------------------------------------------
  4. VENDOR QUERIES
  ---------------------------------------------------------------

  -- ADD NEW VENDOR (Used in: POST /vendor/add)
  INSERT INTO "Vendors" ("Name", "Email", "PAN", "Mobile")
  VALUES ('Rupesh Bhairavi', 'rupesh@gmail.com', 'ABCDE1234F', '08299582058');

  -- LIST ALL VENDORS (Used in: GET /vendor/list)
  SELECT *
  FROM "Vendors"
  ORDER BY "VendorId" DESC;

  -- UPDATE VENDOR (Used in: PUT /vendor/update)
  UPDATE "Vendors"
  SET "Name"   = 'Updated Name',
      "Email"  = 'updated@gmail.com',
      "PAN"    = 'ABCDE1234F',
      "Mobile" = '9999999999'
  WHERE "VendorId" = 1;

  -- DELETE VENDOR (Used in: DELETE /vendor/delete/:id)
  DELETE FROM "Vendors"
  WHERE "VendorId" = 1;

  -- GET VENDOR DETAILS (Used in: GET /vendor/details/:id)
  SELECT *
  FROM "Vendors"
  WHERE "VendorId" = 1;


  ---------------------------------------------------------------
  5. VENDOR TRANSACTION QUERIES
  ---------------------------------------------------------------

  -- GET VENDOR TRANSACTIONS WITH PRODUCT NAME (Used in: GET /vendor/details/:id)
  SELECT
      vt."TransactionId",
      vt."Quantity",
      vt."Price",
      vt."TotalAmount",
      vt."PaidAmount",
      vt."Balance",
      p."ProductName"
  FROM "VendorTransactions" vt
  INNER JOIN "Products" p ON vt."ProductId" = p."ProductId"
  WHERE vt."VendorId" = 1
  ORDER BY vt."TransactionId" DESC;

  -- ADD NEW TRANSACTION (Used in: POST /vendor/transaction/add)
  -- TotalAmount and Balance are calculated in application code:
  --   TotalAmount = Quantity * Price
  --   Balance = TotalAmount - PaidAmount
  INSERT INTO "VendorTransactions"
      ("VendorId", "ProductId", "Quantity", "Price",
       "TotalAmount", "PaidAmount", "Balance")
  VALUES (1, 2, 7, 999.00, 6993.00, 445.00, 6548.00);


  ---------------------------------------------------------------
  6. SALES REPORT QUERIES
  ---------------------------------------------------------------

  -- GET ALL TRANSACTIONS WITH VENDOR AND PRODUCT NAMES
  -- (Used in: GET /sale/list)
  SELECT
      vt."TransactionId",
      vt."Quantity",
      vt."Price",
      vt."TotalAmount",
      vt."PaidAmount",
      vt."Balance",
      p."ProductName",
      v."Name" AS "VendorName"
  FROM "VendorTransactions" vt
  INNER JOIN "Products" p ON vt."ProductId" = p."ProductId"
  INNER JOIN "Vendors" v  ON vt."VendorId"  = v."VendorId"
  ORDER BY vt."TransactionId" DESC;


  ---------------------------------------------------------------
  7. DATA ENDPOINT QUERIES
  ---------------------------------------------------------------

  -- GET ALL USERS (Used in: GET /data)
  SELECT * FROM "Users" LIMIT 100;

  -- GET ALL PRODUCTS (Used in: GET /data)
  SELECT * FROM "Products" LIMIT 100;

  -- GET ALL VENDORS (Used in: GET /data)
  SELECT * FROM "Vendors" LIMIT 100;

  -- GET ALL TRANSACTIONS (Used in: GET /data)
  SELECT * FROM "VendorTransactions" LIMIT 100;


  ---------------------------------------------------------------
  8. USEFUL REPORT QUERIES (Additional)
  ---------------------------------------------------------------

  -- TOTAL SALES SUMMARY
  SELECT
      SUM("TotalAmount") AS "TotalSales",
      SUM("PaidAmount")  AS "TotalPaid",
      SUM("Balance")     AS "TotalBalance"
  FROM "VendorTransactions";

  -- PRODUCT WISE SALES
  SELECT
      p."ProductName",
      SUM(vt."Quantity")    AS "TotalQtySold",
      SUM(vt."TotalAmount") AS "TotalRevenue"
  FROM "VendorTransactions" vt
  INNER JOIN "Products" p ON vt."ProductId" = p."ProductId"
  GROUP BY p."ProductName";

  -- VENDOR WISE OUTSTANDING BALANCE
  SELECT
      v."Name",
      v."Email",
      v."Mobile",
      SUM(vt."Balance") AS "OutstandingBalance"
  FROM "VendorTransactions" vt
  INNER JOIN "Vendors" v ON vt."VendorId" = v."VendorId"
  GROUP BY v."VendorId", v."Name", v."Email", v."Mobile"
  ORDER BY "OutstandingBalance" DESC;


==============================================================================
                      APPLICATION FLOW
==============================================================================

  (I) HOME PAGE (/)
  ------------------
    - Premium enterprise landing page
    - Dark navy background with white card
    - Login and Create Account buttons

  (II) SIGNUP (/signup)
  ----------------------
    - Create new account with:
      Username, Email, Mobile, Password
    - Passwords are hashed using bcrypt

  (III) LOGIN (/login)
  ---------------------
    - Authenticate with Username and Password
    - Redirects to Dashboard on success

  (IV) RESET PASSWORD (/reset-password)
  ---------------------------------------
    - Enter username and new password
    - Updates password hash in database

  (V) DASHBOARD (/dashboard)
  ---------------------------
    - Central navigation hub
    - 6 card-based menu items:
      * Product Master
      * Product List
      * Vendor Master
      * Vendor List
      * Vendor Details
      * Sales Report

  (VI) PRODUCT MASTER (/product-master)
  ---------------------------------------
    - Add new products (Name, Quantity, Price)
    - Edit existing products inline
    - Delete products with confirmation
    - Increase (+) / Decrease (-) quantity buttons
    - All products listed in table below the form

  (VII) PRODUCT LIST (/product-list)
  ------------------------------------
    - Read-only table of all products
    - Columns: ID, Product Name, Quantity, Price

  (VIII) VENDOR MASTER (/vendor-master)
  ---------------------------------------
    - Add vendors (Name, Email, PAN, Mobile)
    - Edit vendor details inline
    - Delete vendors
    - All vendors listed in table below the form

  (IX) VENDOR LIST (/vendor-list)
  --------------------------------
    - Table of all vendors
    - Columns: ID, Name, Email, PAN, Mobile, Details
    - "View Details" button navigates to Vendor Details

  (X) VENDOR DETAILS (/vendor-details/:id)
  ------------------------------------------
    - Full vendor profile at the top
    - "Add Product Transaction" form:
      * Select Product (dropdown)
      * Quantity, Price, Paid Amount
      * Auto-calculated: Total Amount = Quantity x Price
      * Auto-calculated: Balance = Total Amount - Paid Amount
    - Transaction History table:
      * All past transactions for this vendor
      * Color-coded balance (Green/Red)

  (XI) SALES REPORT (/sale-list)
  --------------------------------
    - Summary cards at top:
      * Total Amount (₹)
      * Total Paid (₹) — Green
      * Total Balance (₹) — Orange
    - Full transaction table (8 columns):
      * Transaction ID
      * Vendor Name
      * Product Name
      * Quantity
      * Price (₹)
      * Total Amount (₹)
      * Paid Amount (₹) — Green
      * Balance (₹) — Red/Green based on sign
